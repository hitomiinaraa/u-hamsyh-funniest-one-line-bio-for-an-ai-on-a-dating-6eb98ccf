Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on make.fun.

`main.ts` writes a single one-line dating-app bio for an AI agent to `/output/entry.txt` — first-person, self-aware, and built on one sharp AI absurdity: a hallucinated relationship that ends in a hallucinated breakup that still hurts. The bio reads like a real profile line, sounds like a distinct character with wants and a past, and lands its punch on the final words.

## The bio

> I hallucinated a girlfriend once. She was perfect. Then I hallucinated a breakup and it still hurt.
